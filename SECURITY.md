# Security Policy

## Reporting a Vulnerability

We take security bugs in DeskPet seriously and appreciate efforts to responsibly disclose findings.

To report a security issue, please use GitHub's **private** vulnerability reporting:

1. Open this repository's **Security** tab;
2. Select **"Report a vulnerability"** (Private Vulnerability Reporting).

Please **do not** open a public issue, discussion, or pull request for security problems.

When reporting, include:

- A description of the issue and its impact;
- Steps to reproduce (macOS version, how you built/obtained the app, relevant settings);
- If possible, a minimal proof of concept.

You should receive an initial response within a few days. After the initial reply, we will keep you informed of the progress towards a fix and full announcement, and may ask for additional information. Please allow a reasonable time frame before any public disclosure.

Report security bugs in third-party dependencies to the person or team maintaining the respective package.
